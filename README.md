# On the Identification of the Variation of the Volatility Process from European Option Prices

This repository contains the computational code associated with the manuscript:

Pu Ern Kow, Pu-Zhao Kow. *"On the Identification of the Variation of the Volatility Process from European Option Prices."*

The code is provided to support the numerical experiments and computational results presented in the manuscript.

## Repository Contents

The repository contains the implementation of the numerical procedures and experiments discussed in the manuscript.

## Manuscript Status

The manuscript is currently under revision. The code and accompanying materials may be updated to reflect changes in the revised version.

## Requirements

The code is implemented in Python. Additional dependencies, if required, are specified in the corresponding source files.

## Usage

The source code can be downloaded or cloned from this repository and executed locally. Further details regarding the numerical setup and implementation can be found in the manuscript.
